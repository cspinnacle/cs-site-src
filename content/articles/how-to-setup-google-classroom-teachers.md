Running six sections of CS means six classes to keep organized. Here's the setup checklist, start to finish — useful for a substitute picking things up, a co-teacher, or another CS teacher setting up their own room.

![Illustration of a person adjusting settings on a control panel](https://cdn.undraw.co/illustration/control-panel_s0j2.svg)

## 1. Create the class

From the Classroom home screen, click the **+** in the top corner and choose **Create class**. You'll be asked for:

- **Class name** — keep it consistent across sections, e.g. "AP CSA — Period 3"
- **Section** — useful when you teach the same course multiple times a day
- **Subject** and **Room** — optional, but they make the class list easier to scan later

## 2. Add students

Open the **People** tab. There are two ways to build a roster:

- Share the auto-generated **class code** and have students join themselves (fastest for the first week)
- Invite students directly by school email address (more reliable for younger grades)

Guardians can be invited from this same tab if you want to enable guardian email summaries for a class.

## 3. Set up grading categories

Before posting assignments, decide how the overall grade should be calculated. In **Settings → Grading**, turn on **Overall grade calculation** and choose **Total points** (simplest) or **Weighted by category** (more control). For weighted grading, add categories with percentages that add up to 100 — for example:

```
Projects        40%
Classwork       30%
Assessments     30%
```

Set this up before the first graded assignment goes out — changing category weights after grades exist can shift already-posted scores.

## 4. Create an assignment

From **Classwork**, click **Create → Assignment**. Fill in the instructions, attach any files or a rubric, set the point value, assign it to the right category, and set a due date. **Assign** posts it immediately; the dropdown next to the button also lets you **Schedule** it for a later date, which is useful for prepping a whole unit in advance.

## 5. Grade submitted work

Open the assignment and click **View assignment** (or the student count) to see submissions. Click into a student's work to grade it directly — Classroom supports inline comments on Docs and PDFs, which is usually faster than a private message for pointing at a specific line of code. Enter a score, then click **Return** to release it; grades aren't visible to the student until you do.

## 6. Remember: Classroom isn't the official record

Classroom's own **Grades** tab is genuinely useful for your own tracking, but it is not the school's system of record — that's QuickSchools. Scores still need to make their way into QuickSchools separately on whatever cadence your school expects, so don't rely on Classroom alone at report-card time.

## A tip for multiple sections

Once one section is fully set up — categories, an assignment template, a rubric — use **Classwork → Reuse post** on a new class to copy it over instead of rebuilding it six times. It copies the assignment structure, not the grades or student submissions, so it's safe to reuse across sections all year.

## The one-sentence version

Set grading categories before the first assignment goes out, use guardian summaries and reused posts to save yourself repeated work, and remember Classroom is your workspace — QuickSchools is still the official record.
